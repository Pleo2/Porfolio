## Portfolio website

## Getting started

This project pins its Node.js and npm versions with [Volta](https://volta.sh/). Install Volta, then run the following from the project directory:

```bash
volta install node
npm ci
npm run verify
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the home page. The active routes are `/` and `/blog`.

`npm run verify` runs linting and a production build. Use it before submitting changes.

## Deploy on Vercel

You can deploy this Next.js application through the [Vercel Platform](https://vercel.com/new).
